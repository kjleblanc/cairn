## Limitations and remaining human judgment

- **The stone still counts a claim.** That is the owner's decision, taken
  knowingly: the label moved, the mechanism did not. A worker that claims
  `milestone: YES` on a run nobody demonstrated still mints a stone, and the
  only defence remains the one this repository has used twice — the human
  closing the task writing `NO`.
- **The gloss is on two screens, not four.** The switcher dropdown, the chat
  background scene, and the scene's own aria-label were left alone for the
  reasons given above. If the owner wants the sentence in the switcher too, it
  is one line and one import.
- **The de-duplication is per read, not per file.** A duplicated line stays in
  `.cairn/conversations/NNN.jsonl` forever; it simply renders once. Nothing is
  deleted from an owner's conversation file by this change, and nothing about
  the marker store changed.
- **The staleness guard is mtime-based, not content-based.** Rebuilding core
  with no source change still makes the app bundle "stale" and demands a
  rebuild that changes nothing. That is the fail-closed direction and costs one
  `npm run test:smoke`; a content-hash guard would be a larger change than the
  hole warrants.
- **Marker-file pruning was out of scope** by the brief and was not touched.
