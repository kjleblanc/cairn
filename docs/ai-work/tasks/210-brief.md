## What DONE and STOPPED mean here

**DONE:** both proposal surfaces can show the same source-honest frozen Task
Spec preview while the existing production route remains unchanged and dark.

**STOPPED:** preview authority would require trusting conductor/renderer ids or
source labels, promoting unsure content without a new owner turn, inventing an
unverifiable standard, changing current dispatch behavior, or activating Q4+
work. The report will preserve the state and name the smallest safe next
decision.
