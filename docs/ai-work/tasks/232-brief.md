# Task 232 brief - route safely selected tracked text through one fake Builder turn

**Lane:** A (the main checkout). **Base commit:** `7902306`.

## Requested visible outcome

In one identity-owned disposable Git project, Cairn Main selects bounded current
text from genuine Git-tracked ordinary files, composes the exact Task 224
Builder context from that live custody, sends that exact context once through a
positively guarded injected tool-free fake transport, receives the exact
identity-bound branded response, and passes the same live pair to Task 231's
existing `appendBuilderReviewTurn` boundary. Real desktop Chat receives and,
after a cold relaunch, restores exactly one authenticated, inert **Builder
proposal - not applied** review.

The route is evidence-only. It is unavailable during an ordinary launch, uses
only fixed harmless synthetic text, and neither calls a real Builder model nor
applies, publishes, verifies, approves, dispatches, or executes the proposal.
